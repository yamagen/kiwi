# KIWI

**KIWI** (Keyword In Word Index) is a UTF-8-friendly KWIC (Keyword in Context) / permuted index generator for Japanese text.

This tool allows you to create indexed views of keywords in context, useful for linguistic analysis, digital humanities, and corpus research.

## Features

- UTF-8 support (especially for Japanese kana and kanji)
- Permuted index (rotated keyword) output
- Minimal and fast command-line interface
- Supports piping and batch processing

## Usage

```bash
kiwi input.txt
```
